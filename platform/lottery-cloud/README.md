# LotteryCloud

LotteryCloud is a standalone, owner-only analytics entity for lottery research. It is separate from OwnerCloud, AI2, AI3, Guardian, business revenue, and payment workers.

## Scope
- Texas Pick 3
- Texas Lowball
- Mega Millions

It continuously collects permitted public results/research, runs large-scale simulations and out-of-sample backtests, and produces statistical candidate sets. It never buys tickets, places wagers, moves money, changes business goals, or controls other agents.

## Independence
Run this service as its own process/container with its own state directory and schedule. A browser session is not required.

## Output
Each game receives its own model, dataset, simulation count, backtest metrics, and candidate rankings. Results are statistical—not guarantees of future draws.
